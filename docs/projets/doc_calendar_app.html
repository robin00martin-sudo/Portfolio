#1. Présentation du projet

Le projet Calendrier est une application web PHP réalisée au GRETA-CFA de Bayonne, en autonomie, comme premier projet de développement web. Il génère un calendrier annuel à la française sur trois années consécutives à partir d'une année de départ, en respectant les jours fériés fixes et mobiles, le rattache à une formation stockée en base de données, permet de surligner en violet des journées sélectionnées et d'exporter le résultat en PDF.

Le projet reste volontairement simple (pas de framework, PHP et JavaScript dans les mêmes fichiers). Cette documentation décrit la version corrigée du dépôt.

#1.1 Besoin métier

  • Produire un planning annuel imprimable pour chaque formation du centre (CAP, BTS, titres professionnels, diplômes d'État).
  • Afficher automatiquement les jours fériés français, sans saisie manuelle.
  • Permettre de marquer des périodes (vacances, examens, stages…) sur le calendrier avant impression.
  • Fournir un PDF prêt à diffuser (un calendrier par page, A4 paysage).

#5. Détail du code

#5.1 Connexion – config.php

Les identifiants ne sont plus dans le code : config.local.php (copié depuis config.example.php) est ignoré par Git. À défaut, les variables d'environnement DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS sont utilisées.

#5.2 function_optimize.php

#Plage d'années

easter_date() ne fonctionne qu'à partir de 1970 et, avant PHP 8.3 (ou en 32 bits), jusqu'à 2037 ; ensuite jusqu'à 2099. Comme le calendrier affiche 3 années d'affilée, l'année de départ doit laisser 2 années de marge.

FonctionRôle
anneeMin()1970.
anneeMax()2097 (PHP ≥ 8.3 en 64 bits) ou 2035 sinon.
lireAnnee($valeur)filter_var(..., FILTER_VALIDATE_INT, min_range/max_range) : retourne l'entier ou null.
paques($year)Date du dimanche de Pâques (easter_date).
addDaysToPaques($year, $days)Ajoute $days jours à Pâques (strtotime).
jours_feries($year)Liste de 11 dates (voir ci-dessous).
generateCalendarAnnuaire($year, $formation)Écrit le bloc .calendrier.

#Jours fériés

Fixes (8) : 1er janvier, 1er mai, 8 mai, 14 juillet, 15 août, 1er novembre, 11 novembre, 25 décembre. Mobiles (3), calculés depuis le dimanche de Pâques :

FériéDécalage202620272028
Lundi de Pâques+106/0429/0317/04
Jeudi de l'Ascension+3914/0506/0525/05
Lundi de Pentecôte+5025/0517/0505/06

Le dimanche de Pâques et le dimanche de Pentecôte sont déjà des dimanches : inutile de les lister.

#Génération du tableau

  • Structure : 1 ligne d'en-tête (12 cellules <th colspan="3">) puis 31 lignes ; chaque mois occupe 3 colonnes (36 au total).
  • Contenu d'un jour : initiale (L M Me J V S D), numéro, cellule vide (zone de note).
  • Jours inexistants : si $day > cal_days_in_month(CAL_GREGORIAN, $month, $year), trois cellules class='empty' (les années bissextiles sont gérées).
  • Jour de la semaine : date('N', strtotime($date)) (1 = lundi … 7 = dimanche).
  • Priorité des couleurs : férié (holiday, rouge) avant week-end (weekend).
  • Titre : intitulé de la formation (échappé) et Année XXXX (ancre id='yearXXXX').

#5.3 index.php

  • Charge config.php et function_optimize.php.
  • Lit les formations dans un try/catch : si la base est inaccessible, le détail est journalisé (error_log) et l'utilisateur voit « Impossible de contacter la base de données. ».
  • Formation présélectionnée : filter_input(INPUT_GET, 'formation', FILTER_VALIDATE_INT).
  • Année par défaut : année demandée si valide, sinon max(anneeMin(), min(date('Y'), anneeMax())).
  • Les attributs min et max du champ année sont ceux de anneeMin() / anneeMax() : le formulaire et le serveur utilisent la même règle.
  • Messages d'erreur : « Année invalide : choisissez une année entre 1970 et 2097. » ou « Formation introuvable… ».
  • Toutes les sorties passent par htmlspecialchars().

#5.4 calendrier.php

  • PHP en tête de fichier, avant tout HTML : validation, requête, éventuelle redirection.
  • CSS en ligne : <style><?php include __DIR__ . '/styleCalendrier.css'; ?></style>.
  • Barre de navigation position: sticky (liens index.php, ancres des 3 années, #download).
  • Spinner #spinner masqué par défaut, affiché pendant l'export.

#5.5 Sélection de jours

Chaque jour est représenté par trois cellules contiguës ; l'index de la cellule cliquée est ramené au début de son groupe (index - (index % 3)), puis les trois cellules sont basculées ensemble.

.selected-day (violet) est déclarée après .holiday et .weekend dans le CSS : la sélection recouvre ces couleurs.
